# Claude Code for Non-Coders

This repository contains a series of interactive slide modules designed to help non-technical users master AI workflows and leverage powerful tools like Claude Code.

## Modules

### [Module 01: Why Chat AI Is Not Enough](slides/module01-slides-final-v2.html)
Explores the limitations of standard chat interfaces and the transition toward more advanced AI integration.

### [Module 02: Your AI Workflow Workspace](slides/module02-slides.html)
Setting up the ideal environment and tools for efficient AI-assisted work.

### [Module 03: Building Your First Workflow](slides/module03-slides.html)
A practical guide to designing and executing your first automated or semi-automated AI workflow.

### [Module 04: AI Roles, Skills & Advanced Design](slides/module04-slides.html)
Deep dive into specialized AI roles, essential skills for the AI era, and advanced workflow design patterns.

## How to View
To view the slides, simply open any of the `.html` files in the `slides/` directory in your preferred web browser.
