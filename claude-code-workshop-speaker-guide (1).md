## Section 2 — Folder Structure

**Slide:** `Workspace Architecture`

### Keywords

- organization
- readable context
- AI navigation
- operational memory

### Speaker Script

> “Folder structure is not for humans only.
>
> It’s for AI navigation.”
>
> “Good structure reduces hallucination.”

### Claude Code Switch

**Show Example Structure:**

```text
00-start-here/
01-context/
02-inputs/
03-templates/
04-ai-roles/
05-outputs/
06-review/
```

### Explain Each Folder

| Folder | Purpose |
|---|---|
| `00-start-here/` | Entry point, mission, onboarding notes |
| `01-context/` | Client, brand, project, and background knowledge |
| `02-inputs/` | Raw briefs, meeting notes, documents, source material |
| `03-templates/` | Reusable output formats and standards |
| `04-ai-roles/` | Role files and agent behavior definitions |
| `05-outputs/` | Final deliverables and generated work |
| `06-review/` | QA checklist, review notes, human approval records |
